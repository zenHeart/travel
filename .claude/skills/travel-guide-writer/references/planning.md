# 从约束生成可执行攻略

用于选酒店、排新行程与修改关键日期，不输出成面向家人的研究报告。

## 输入与证据分开

先列工作用约束表：值、状态、来源、适用人／日期、受影响页面。简单任务在工作上下文完成，无需新建公开文档；复杂调研记录放项目忽略的任务产物目录。

| 状态 | 能支持什么 | 不能支持什么 |
| --- | --- | --- |
| 用户确认／订单凭据 | 本次班次、完整分店、权益与完成状态 | 自动推广为永久偏好或其他人的权益 |
| 当次查询 | 来源覆盖日期、房型、人数下的规则或报价 | 已订成功；展示起价等于家庭结算价 |
| 计划估时 | 行走、候车、餐饮、活动安排与余量 | 官方时刻、保证不排队或来得及 |
| 待确认 | 核对动作、候选、受影响下一步 | 填精确数字后当作确认 |

外部现价不会改写用户已付金额。订单资料冲突时先定位字段，不猜哪个版本正确。逐项记录核验日期，避免用页面级 verified_at 掩盖未核验项目。

## 酒店怎么选

### 先判能不能住，再判值不值得

1. **实际可住**：完整分店、入住／退房、几晚几间、成人儿童人数与年龄、房型床型、儿童同住、晚到接待。午夜后到店要明确占用哪一晚，不把凌晨到店的当天日期误当成应订入住日。
2. **实际可休息**：睡眠需求、房间可用时段、退房后午休、延迟退房或钟点房。未获酒店答复的“免费延迟”“可寄存”“双早含孩子”保持待确认。
3. **整条路线匹配**：落地接驳、次日首站、每日午休往返、餐饮、末日车站；查出入口、电梯、换乘和步行，不拿直线距离当门到门耗时。
4. **真实成本与风险**：同日期、同人数、同房数比较含税总价，另计早餐／加床／儿童／寄存／接驳、押金与退改。折算人均或每晚时保留完整口径，套餐里的房与票不重复计账。

有明确预算和偏好则按其筛选。未要求排名权重时不造综合评分，保留少量可执行候选并讲清关键取舍。未核验床型、卫生、隔音就列核对动作，不以品牌或单篇评价保证质量。

### 不同住宿用途

- **晚到过渡**：接驳、夜间入住、睡眠和次日行李处理；便宜航班增加的接驳与睡眠代价一起算。
- **城市连住**：围绕实际活动半径与午休选择，计算搬家新增的退房、寄存、等待和交通。
- **园区／度假酒店**：套餐人数、票效日期、多次入园、用餐、退房后权益，按同等权益比较整包和外住。
- **白天休息房**：有床、地点、可用起止、最短计费、证件与退改；未落实就缩短外出或提前回已订酒店。

选定后执行页只留完整分店、地址与必要联系方式、到离店动作、权益和待办，候选与淘汰原因退出正文。用户要比较时另给决策摘要，选定后收敛。

## 行程怎么排

### 从硬时刻倒推

先放已订交通、门票预约和实际入住时段，再放睡眠、正餐、本次所需午休和存取行李，剩余时间安排主活动与沿线食物。跨城逐段核对：

`出门 → 步行／等车 → 接驳 → 出入站／边检 → 安检候车 → 发车 → 抵达出站 → 下一段接驳`

每段有依据或标明预留，不把列车运行 8 分钟写成全程 8 分钟。停检／登车截止、建议到站时间、最早可办理时间是三个不同字段。

用最迟必须到达的时刻倒推离开活动的时间。窗口不够就减活动或换未订方案，不压缩睡眠、边检、接驳等现实开销去凑表。

### 完整的一天

- 从起床或本次抵达到回房或下一程交接，不能漏正餐、取箱、退房、会合。
- 按地理邻近排序，查去回路线，不因景点知名就反复跨区穿插。
- 有午睡需求时，床、往返交通、使用时段一起落实。退房后“回酒店午休”要有延迟退房、钟点房或下一间房依据。
- 办事与游玩并行时写每组去哪里、谁照看孩子、何处会合、最晚何时放弃办理；不承诺银行等未知结果。
- 一条主线，必要异常写“遇到 X，执行 Y”，并确认替代动作能做；早返需要实际可用车次，不是写“早点回”就完成。
- 疲劳、雨、排队等阈值按本轮需求；未知时作为计划余量，不写成用户固定偏好。成人独行、亲子、长辈、无障碍场景分别适配。

## 交通与预算

- 尚未决定交通时比较现实可行的飞机、高铁等，按同日、实际同行人、行李与始终点计算总费用和门到门时间。
- 核对查询日期、币种、成人儿童、税费、附加包、行李、优惠资格和库存；日历低价起、学生价与成人展示价不能直接乘人数。
- 预算先明确包括哪些项目。押金、银行周转资金与实际消费分开，不把退回押金当支出。
- 已订订单是锚点；若改线有价值，先给退改成本和全局影响，用户选择后更新，不因新候选便宜就改已订事实。

## 美食与图片

按沿线街区、具体分店、菜品组织。区分官方资料、地图定位和个人点评各能证明什么，未知营业／现价不编。未核实店名可先写用餐区域与待确定动作。

图片只为认路、园区结构或真实体验服务，保留已有可用地图与原始来源；没有可靠图片可不附图。不生成貌似真实的景点图充当现场证据，不为“丰富”堆图。

## 修改影响链与事实归属

| 改动 | 必须回查 |
| --- | --- |
| 航班变晚、到站变更 | 接驳、跨午夜保房、早餐与次日起床、首个景点、午休 |
| 更换酒店或分店 | 到店路线、每日出门／回房耗时、早餐、取箱、返程、准备清单及 frontmatter |
| 日期或晚数变更 | 分页日期、入住退房、房晚覆盖、票效、预约、退款 |
| 同行人／年龄／身高变化 | 房型、儿童同住／早餐／票种、实名登记、节奏、照看、总价 |
| 取消地点或分支 | 旧链接导航、相关预订、用品、元数据、有价值来源归位 |

总览拥有全程准备与订单摘要；城市拥有当天顺序；吃与景点拥有对应详情；专题拥有深入操作。必须随手可见的时刻可短写多次，同一订单完整金额／权益不在每页复制。修改时搜索旧日期、旧分店与旧路线，防止正文改了而元数据仍旧。
