# 历史游记写法与验收

## 参考哪些内容

- `content/trip/2019-xian-nanjing-hangzhou/hangzhou.md` 的 `## 行程`：每条先写时间再写地点或动作，午餐下面直接列菜。
- `content/trip/2019-xian-nanjing-hangzhou/xian.md` 的 `## 吃`：按回民街、永兴坊分组，再列店名和食物，说明短。
- `content/trip/2022-10-02-chongqing/README.md` 的八一好吃街段落：餐馆、食物用子列表，不写餐饮选择报告。

只继承结构与简洁程度。原作者的亲历评价、当年价格、已走过的实际耗时不复制为新旅行的体验与现价；历史文件本身不因为新风格要求而被重写。

## 句子怎么处理

| 原句类型 | 处理方式 | 可执行写法 |
| --- | --- | --- |
| 「顺德与广州怎么选」「顺德是否值得一天」 | 删除论证，把选定目的地落进日期 | `### 10.1 顺德大良` |
| 「不为只睡一晚付园区房溢价」 | 删除推论，保留住宿动作 | 「预订横琴酒店，25 日入住、27 日退房。」 |
| 「已确定／待预订」总括段 | 删除重复状态，保留待办 | `- [ ] 购买返程票，核对三人乘车资料。` |
| 「广府、潮汕、客家菜系……」百科 | 换成本次路线实际会吃的店与菜 | 「炒牛奶：顺德特色奶食，午餐点一份分尝。」 |
| 整章「留广州两天备选」 | 删除整套分支，保留当天必要异常动作 | 「未订到午休房，午餐后回广州酒店。」 |
| 「XX 非常好吃、亲测必吃」但没有亲历 | 改成有据可查的特色或位置 | 「云吞面：广州代表面食，逛宝华路时吃。」 |
| 「核对店铺信息」 | 补齐具体执行对象 | 「致电所选分店，确认 1 日午餐订位、地址、儿童椅和收费。」 |

## 内容分工

- **行程**：一天按顺序走完，必要交通、吃饭、休息、取行李不能靠读者自行补齐。
- **吃**：街区 → 店名 → 菜名和一句特色，地址只写一次；餐馆明确分店。未核实的价格和营业时间不填。
- **准备事项**：按类目勾选，包含原文全部适用的关键动作。没有完成凭据时保持未勾选。
- **异常处理**：写在受影响步骤旁，一句触发条件加动作；保留赶车、下雨、预约失败等实际需要，不衍生成一篇方案论证。
- **来源**：在事实旁保留简短可点击链接，查询价附日期。无需公开搜索词、工具调用、访谈式研究过程或重复证据段落。

## 改写验收

每次改写人工检查这些项目；结构检查通过不能代替内容检查。

- [ ] 正文只有行动、地点与食物特色、必要事实和提醒；没有“怎么选／值不值得／推荐逻辑”等论证章节。
- [ ] 日期下是带反引号时间的列表；用户要求清单时为可勾选项。未确定交通时刻不伪造具体分钟。
- [ ] `## 吃` 按街区与门店罗列，每道食物一句理由；没有菜系百科、跨城比较或整表“适合谁”。
- [ ] 主路线明确；没有完整重复的第二套路线，也没有为了精简丢掉必要的条件动作。
- [ ] 证件、预订、儿童、休息、行李、返程等适用的原有要求都能找到；不重复大段说明。
- [ ] 用户已要求的分页和父子层级保留；首页摘要与城市页日期相符。
- [ ] 已完成项没有被无凭据勾选；查询有票没有写成已购票；历史体验没有冒充本次亲历。
- [ ] 来源与事实匹配，计划时段和官方时刻可区分。
- [ ] 内容审计、构建通过，用户指定页面实际显示新正文；未执行的验证不报通过。

## 技能回归场景

这是一组复用的人工验收场景，不是自动通过记录。改技能后至少用本次真实页面走一遍，未执行的场景只保留为检查案例。

| 输入 | 查看范围 | 期望行为 | 失败表现 |
| --- | --- | --- | --- |
| 「按历史游记改广州页，删掉怎么选，美食简洁列出」 | 目标页、杭州行程、西安美食、总览 | 一条按天清单，`## 吃` 按街区与店列菜和理由 | 换个名字保留对比表；把菜写成百科 |
| 「精简攻略，但雨衣、漫游、预约、入境小票别漏」 | 原准备清单、长隆页、办卡页 | 适用动作仍在 checklist 或详细流程，能逐项对应 | 删除准备事项只留下景点名 |
| 「长隆归珠海、办卡归香港，显示层级」 | README、城市页、嵌套页、扫描器 | 复用父子结构、修正相对链接 | 因旧技能“一份 index.md”强制合并 |
| 「去掉已确定、待预订」 | 页首与 checklist | 页首状态段删除，完成状态由 checkbox 记录 | 自动勾选所有订单或把事实核验删掉 |
| 「把新餐馆写成我历史的短评样式」 | 历史食物条目、门店来源 | 写简短客观特色，保留真实分店信息 | 虚构“亲测好吃”或未经核验的价格 |
