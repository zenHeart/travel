# 城市中文名

入住至退房日期、住宿落点。说明哪些时刻为已订交通，哪些为计划安排。

## 行程

### YYYY-MM-DD · 当天主题

1. `已核验时刻或计划时段` 从起点出发，到达地点；写清换乘、步行与所需余量。
2. `计划时段` 当天主要活动。
3. `计划时段` 午饭，具体分店或尚待确定的用餐区域。
4. `计划时段` 按本次节奏休息；需要床上午休时，核对房间与可用时段，未落实则写待办和当天退路。
5. `计划时段` 下午活动、晚饭、回房或取行李赶下一程。

仅在实际需要时补一句条件动作，例如未订到午休房则午餐后早返，较早返程交通须先落实。
