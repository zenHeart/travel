# 行程名称

## 整体行程

起止日期、天数与晚数、实际同行人；本次节奏和必要行李条件。

- **YYYY-MM-DD** 城市、当天主活动、夜宿落点。

逐日时间轴、吃与景点：链接实际存在的城市分页。

## 出发准备

1. **证件与订单**

   - [ ] 核对本次同行人的证件、有效期、预约与实名资料，保存可离线使用的订单。

2. **交通与住宿**

   - [ ] 落实出入程交通与实际房型，核对入住退房、同行人权益、到店时间、取消期限及行李安排。

3. **门票、餐饮与休息**

   - [ ] 落实本次必要预约及休息空间，核对日期、使用时段与人数。

4. **随身准备**

   - [ ] 根据天气、活动和同行人整理证件、网络支付、药品与行李。
