# 珠海长隆：一天海洋王国＋一晚横琴

## 园区地图

![珠海长隆海洋王国园区地图](https://cdn.chimelong.com/upload/cd9cd113686553f6/a74c67829f026c8b.jpg)

进园后先去较深处的鲸鲨馆，再顺路看海底互动船；下午把企鹅馆、北极熊馆等极地区场馆放在一起。入园时取当日地图，按现场路线与演出排期调整。

## 9.27：海洋王国一日路线

* 08:30-10:00 从珠海市区退房，去横琴酒店寄存行李、取票；实际入园时间以当天公告为准。
* 10:00-11:00 直奔鲸鲨馆，看水底长廊、大观赏屏，先满足孩子看大鱼的愿望。
* 11:00-11:40 看海底互动船的现场身高要求和排队时间；排队太长就改逛海牛馆。
* 11:40-12:30 顺路看白鲸馆或北极熊馆，不跨园追固定场次。
* 12:30-13:30 午餐；附近餐厅有合适座位就吃，避免为餐厅排长队。
* 13:30-15:30 在园内找阴凉处推车午睡；酒店确认可提前入住且往返方便时再回房休息，出园前办理当日再次入园手续。
* 15:30-16:30 看企鹅馆、北极熊馆；进冷气较强的室内馆给孩子加薄外套。
* 16:30-17:30 白鲸、海豚或海狮剧场选一场当天有排期且不需久等的；提前到场。
* 17:30-19:00 吃晚饭，按孩子体力复玩一个喜欢的项目；5D 影院仅在孩子能接受声光效果时参加。
* 19:00 后 按当天公告和孩子状态看夜光巡游或烟花；累了直接回酒店，不为等烟花熬夜。

## 9.28：横琴休息与转场

* 08:30-10:00 睡到自然醒，在酒店吃早餐。
* 10:00-12:00 退房并前往珠海市区酒店；当天不再入园。
* 12:00-15:00 午餐、办理入住；房间未备好时让孩子在推车上休息。
* 15:00-17:00 房间午睡或在附近海边玩沙，按孩子状态选择。
* 17:00-19:00 晚餐，整理次日香港入境证件和随身包。

## 场馆与取舍

| 优先级 | 项目 | 到场动作 |
| --- | --- | --- |
| 必看 | 鲸鲨馆 | 留足 45–60 分钟，沿水底长廊慢慢看；拥挤时先看其他展缸，稍后回大观赏屏 |
| 必看 | 企鹅馆、北极熊馆、白鲸馆 | 归在极地探险区，沿路选重点；进室内馆给孩子加薄外套 |
| 看排队 | 海底互动船 | 入队前看现场身高要求、等候时间和孩子是否愿意坐 |
| 三选一 | 白鲸/海豚/海狮剧场 | 当天只锁一场；按官方公布的场次提前到场 |
| 看接受度 | 5D 城堡影院 | 可能有较强声光、座椅动作和喷水；孩子害怕就跳过 |
| 可放弃 | 过山车、激流等刺激项目 | 不按年龄推测身高，也不为买了票强行体验 |
| 可放弃 | 夜间巡游、烟花 | 场次可能调整；孩子困了就回酒店 |

## 入园与午休

- [ ] 购票前核对 9.27 **一日海洋王国**门票、实名要求、三人的适用票种和儿童票条件；一晚含票酒店套餐与分别购买按三人总价比较。
- [ ] 带购票所用身份证件；入园前查看当天开园时间、表演场次、设施关闭公告。
- [ ] 优先订距园区近、可以寄存行李的横琴酒店；预订时确认步行/接驳时间、入住与退房时间。想在房间午睡须提前确认 9.27 午前可入住。
- [ ] 若午休回酒店，出园前到入闸口办理当天再次入园手续。
- [ ] 自带轻便婴儿推车、遮阳帽、防晒用品、薄外套、雨具和本人适量饮用水。园区允许婴儿车；露营车、滑板车及带儿童座椅的行李箱不可入园。
- [ ] 园区食品规则是除婴儿食品和本人适量饮用水外，谢绝带入其他食品饮品；儿童零食不要按旧攻略直接装包。
- [ ] 入队前看现场身高和安全提示；孩子净身高未量，不预设海底互动船或任何机动项目一定能玩。

## 预算控制

- 横琴一晚住宿上限 ¥1,100；长隆三人一日票上限 ¥1,800。若买含票房包，酒店和票只计一次总价。
- 园内餐饮、接驳及纪念品另计；安排一顿普通园内午餐即可，不预设企鹅自助餐或快速通道。
- 如一日票/房包超过上限，优先保留海洋王国核心场馆与午休时间，再缩减高价房型和额外体验。
