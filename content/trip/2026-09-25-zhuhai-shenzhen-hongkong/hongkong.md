# 香港：29 日办卡，30 日玩到下午

**住一晚尖沙咀。** 选能寄存行李、离尖沙咀分行与中港城／九龙公园较近的正规酒店。29 日把银行任务放在前面；家人先在九龙公园一带活动，不让孩子陪跑柜台。[办卡指南](./hongkong/banking.md)单独列材料、App、分行和 X 收益资格。

## 9 月 29 日

| 时间 | 行动 |
| --- | --- |
| 07:15–11:30 | 从蛇口酒店带行李经福田口岸／落马洲到香港。收齐三人入境小票，测试网络和收短信，再到尖沙咀酒店寄行李。保存寄存牌，带走证件与银行材料；实际抵达时间受路况和通关排队影响。 |
| 11:30–12:15 | 尖沙咀／佐敦一带吃**港式茶餐厅**：菠萝油、奶茶、通粉、云吞面；给孩子点粥面。 |
| 12:15–13:45 | 开户人下载含当天内地出境记录的电子文件、用中银香港 App 申请银行账户。另一位成人带孩子在**九龙公园**活动，或找室内座位休息；酒店通知房间可入住后回房午睡。 |
| 13:45–16:30 | 开户人到已预约的尖沙咀或堪富利士道分行办证券和美股服务；结果以银行审核为准。家人在酒店／九龙公园附近休息。 |
| 16:30–18:00 | 会合后沿**星光大道—尖沙咀海滨—旧九广铁路钟楼**慢走；看维港和港岛天际线。 |
| 18:00–20:00 | 海滨附近吃饭；孩子有精神就看晚间维港夜景，累了直接回酒店。想坐**天星小轮**，可在这一晚尖沙咀→中环→尖沙咀往返；班次与收费按[官网](https://www.starferry.com.hk/tc/service)当天查。 |
| 回房后 | 核对储蓄／外汇宝、证券及美股状态，保存回执、补件要求与小票；按[办卡指南](./hongkong/banking.md)申请扣账卡。核对次日车票和出发提醒。 |

### 29 日到港后逐项完成

- [ ] **入境小票**：三张收齐，核对姓名、日期、逗留期限，拍照后将原件放防水证件夹；办卡时交柜员查看，结束后收回。
- [ ] **网络**：保留内地 SIM 启用，测试本人号码接收短信；按所购流量套餐设置上网卡和数据漫游。另一位成人也能独立上网、联系与导航。
- [ ] **交通支付**：港铁客务中心购买／充值成人及小童八达通，先问按金、充值与退款条件；三人分卡使用，留部分港币现金。
- [ ] **酒店寄存**：记录行李件数、领取时段，拍寄存牌；两位成人均登记，孩子随身包带在身边。
- [ ] **分开活动**：约好办卡后会合点，双方都有酒店定位与电话；银行材料、手机和证件留给开户人，另一位成人保管自己和孩子的证件。
- [ ] **餐饮**：先看菜单的服务费与支付方式；孩子先吃粥面等主食，茶饮点给成人。游览途中及时补水、上洗手间。

## 9 月 30 日

上午在尖沙咀活动，下午从香港西九龙站乘高铁去广州。

**29 日银行要求本人补材料时**：先确认分行 30 日上午能受理，再将 10:00–11:30 艺术馆替换为补办，另一位成人陪孩子在酒店周边活动。出发去西九龙的时间按车票固定下来，未完成事项向银行确认后续处理方式。

| 时间 | 行动 |
| --- | --- |
| 08:30–10:00 | 早餐、退房，行李寄存在酒店；预订时要确认可寄存到午后。 |
| 10:00–11:30 | **香港艺术馆**看常设展，或者沿星光大道补拍白天维港；馆方公布周三开放至 18:00，但国庆前一天仍查当天公告。[开放信息](https://hk.art.museum/sc/web/ma/visit/opening-hours-and-admission.html) |
| 11:30–13:00 | 尖沙咀午餐、孩子休息；天星小轮尽量放在前晚。午后按实际车次提前结束活动。 |
| 13:00–14:00 | 回酒店取行李，赴**香港西九龙站**。目标是开车前 90 分钟到站；若买到较早车次，取行李和午餐同步前移。 |
| 15:00 后 | 香港西九龙→广州南，具体车次与到站时间以所购车票为准。[港铁高铁票价](https://www.highspeed.mtr.com.hk/tc/ticket/fare.html) |
| 抵广州后 | 地铁／打车到公园前或北京路附近酒店，晚餐就近找**粤式煲仔饭或糖水**，早点休息。 |

西九龙→广州南无票时，查询经深圳北／福田换乘到广州南的车次，并按实际车票安排过关与换乘时间。

### 30 日离港与乘车 checklist

- [ ] **退房**：拿到押金处理凭证，确认寄存可领到几点；决定是否保留八达通，需退款时先问办理地点与费用，不在临近发车时绕路。
- [ ] **取行李**：按寄存件数取齐，清点三人证件、入境小票、银行回执、推车和充电器；孩子先上洗手间，准备车上水和零食。
- [ ] **车票**：确认“香港西九龙→广州南”、日期、车次、座位及孩子购票／免费随行登记；携带购票所用证件原件，以及三人出入境需要的通行证等材料。
- [ ] **到站**：按开车前 90 分钟到达的目标安排交通。例如 15:00 开车，13:30 到站；再按地图车程和酒店取行李用时提前出发。这是时间示例，车次尚待购买。
- [ ] **进站通关**：B1 实名验证及检票 → 安检 → B3 办香港和内地出入境手续 → 到所乘列车的检票口候车 → 按广播登车。实名验证及检票在开车前 **30 分钟**停止，登车闸机在开车前 **5 分钟**关闭；带娃按站内人员指引使用相应通道。[港铁乘车流程](https://www.highspeed.mtr.com.hk/tc/guide/process-departure.html)
- [ ] **抵达广州南**：清点随身物品后出闸，确认手机恢复内地上网卡与网络，给广州酒店报预计到店时间。乘地铁 2 号线往嘉禾望岗方向至公园前，或按酒店位置打车。
