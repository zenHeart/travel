# 长隆玩法：9 月 27–28 日住一晚、玩两天

## 两种房包

| 方案 | 票面内容 | 27–28 日安排 |
| --- | --- | --- |
| **海洋王国 2 天 1 晚家庭单园** | 核对 2 大 1 小两日门票、一晚房和早餐 | **本行程选此方案**：27 日看场馆和夜间节目；28 日上午补场馆，午后乘船。[企鹅酒店官网房包](https://www.chimelong.com/zh/Penguinhotel/) |
| **海洋王国 + 飞船乐园 2 天 1 晚** | 核对两园各自的有效日期、入园次数、三人票种及早餐 | 27 日海洋王国，28 日飞船乐园至午间，随后乘 16:00 船。企鹅酒店官网另列 3 天 2 晚双园套餐；购买 2 天 1 晚商品时以所选商品条款为准。[官网套餐](https://www.chimelong.com/zh/Penguinhotel/) |

两种商品均核对 **2 大 1 小含税总价**、儿童票、早餐、有效日期及退改。长隆官网将已满 3 岁或身高达 1 米的儿童列为儿童票对象。[官方票种](https://www.chimelong.com/zh/ticket/)

企鹅酒店到海洋王国步行约 3–5 分钟；马戏酒店约 10–15 分钟；飞船酒店连接飞船乐园。[长隆 9 月接驳说明](https://www.chimelong.com/zh/traffic/type_7.html) 付款前查看所选酒店的寄存、提前入园和两日入园条款。

## 27 日：鲸鲨馆、极地馆、夜间节目

表内为游玩计划；27、28 日开园和提前入园时间按当日公告及房包权益调整。

| 时间 | 行动 |
| --- | --- |
| 08:00–09:00 | 横琴普通酒店退房，园区酒店寄存行李、核销 2 大 1 小房包；问清当日入园、再次入园和早餐权益。保存寄存牌，带雨衣、替换衣及证件进园。若房包含提前入园，按酒店告知时间到检票口。 |
| 09:00–10:30 | **鲸鲨馆**：大观赏屏和海底长廊。 |
| 10:30–12:00 | 海底互动船按现场身高和排队情况选；排队过长转海牛馆。 |
| 12:00–13:00 | 园内午餐，给孩子准备清淡主食和水。 |
| 13:00–15:30 | 在阴凉处推车午睡，或酒店通知可入住后回房午睡；企鹅酒店常规 15:00 后入住，提前到店先寄存。出园前问清二次入园识别规则。 |
| 15:30–17:30 | 企鹅馆、北极熊馆、白鲸馆；按当天排期看一场动物剧场。 |
| 17:30–夜间节目 | 晚餐后看巡游或烟花。先上洗手间、补水；选便于离场的位置，孩子怕响声就移远一些或回酒店。确切时间及是否举办，以当天园区公告为准。 |

## 28 日：补热门场馆，给 16:00 船留余量

| 时间 | 行动 |
| --- | --- |
| 08:00–09:00 | 早餐、退房、寄存行李；若有提前入园权益，直接复玩昨日没玩到的项目。 |
| 09:00–11:30 | 重看鲸鲨馆或企鹅馆，补一场前一日错过的演出。 |
| 11:30–12:30 | 午餐、最后一次园内休息；不要为刺激项目排长队。 |
| 12:30–13:30 | 回酒店取行李、叫车去横琴客运码头。 |
| 14:45 左右 | 到码头核对船班、安检与行李；订单要求更早到场则以订单为准。 |
| 16:00–17:15 | 计划乘船直达深圳蛇口；当前尚未购票，出票后按订单航次执行。[横琴官方时刻表](https://www.hengqin.gov.cn/ghhjsj/2024/jtzx/hqggjt/hqmt/hbskb/) |

若只买到 18:00 船，按新订单倒推取行李与到码头时间，蛇口晚餐和休息顺延。停航时先联系承运方退改，再查 **珠海站→广州南→深圳北**同站换乘列车，两段有票后购票，从深圳北前往蛇口酒店；道路和铁路同样查看天气与停运公告，告知酒店预计晚到。当天全部交通受影响时留在安全室内，与酒店及后续订单逐一办理调整。

## 地图与现场清单

![珠海长隆海洋王国园区地图](https://cdn.chimelong.com/upload/cd9cd113686553f6/a74c67829f026c8b.jpg)

- [ ] 出发前截图**两日房包三人明细**：27 日入住／28 日退房、两大一小、酒店房型、两日进园及退改。
- [ ] 三人的购票证件原件带齐，量孩子身高；机动项目逐项看现场限制，不按年龄猜能否玩。
- [ ] **雨衣**：成人 2 件、儿童 1 件，另带备用一套；装随身包，玩涉水项目时按现场要求穿戴，先核对身高与陪同限制。
- [ ] **换洗**：孩子衣裤、内衣、袜子 2 套，成人各一件备用上衣；带小毛巾、湿衣密封袋、手机防水袋。湿衣及时更换，去看冷气场馆前先擦干。
- [ ] **推车与防晒**：轻便折叠推车、雨罩、防晒用品、帽子、薄外套和水杯。推车停到指定区域，贵重物品随身；午睡找阴凉处，雨罩按需使用并保持通风。
- [ ] **餐饮与休息**：入园先定位洗手间、母婴室、医务点，午餐前给水杯补水。食品、容器、推车和二次入园要求按[官方游园须知](https://www.chimelong.com/zh/oceankingdom/notice/)及现场指引核对。
- [ ] 27、28 日早晨各查一次园区营业、演出和设施公告；烟花、巡游不作为刚性承诺。
- [ ] 28 日船票买横琴客运码头→蛇口邮轮母港，别把“珠海九洲港”误选为起点。
- [ ] **27 日酒店登记时**：核对入住／退房、早餐地点和时段、儿童补价、两日票核销方式；保存入园凭证与寄存牌，原件放回证件夹。
- [ ] **28 日退房时**：按酒店规定办理退房；企鹅酒店官网为 11:00 前，上午进园前先退房寄存。核对寄存件数、领取位置和电话，留好取行李凭证。[酒店说明](https://www.chimelong.com/zh/Penguinhotel/)
- [ ] **28 日离园时**：先上洗手间、换掉湿衣、补水，再取齐箱子和推车；打车目的地选择“横琴客运码头”，到港按订单要求取票安检。
