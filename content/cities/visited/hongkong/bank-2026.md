# 28 日上午：香港开户保姆级实操攻略

利用 28 日（周一正常工作日）上午 09:00—11:30 的时间窗口，单独前往尖沙咀分行办理香港银行卡。办完后在尖沙咀与家人汇合午餐。

## 必备材料清单（随身携带）

1. **身份证原件**：二代居民身份证（剩余有效期需大于 6 个月）。
2. **港澳通行证原件**：在有效签注期内。
3. **入境小白条（极度重要）**：
   - 28 日早晨在落马洲管制站过闸机时自动打印的小纸片（上面印有姓名、通行证号、入境日期及停留期限）。
   - 入境后立刻拍照存入手机相册，原件夹在通行证内切勿丢失。
4. **出入境记录凭证**：
   - 入境香港后，微信搜索打开“国家移民管理局”小程序。
   - 依次点击“业务办理” → “出入境记录查询” → 身份认证 → 生成带有国家移民管理局电子印章的最新记录 PDF，发送到手机微信备用。
5. **地址证明（近 3 个月）**：
   - 带有本人姓名和常住居住地址的招商银行/建设银行信用卡对账单（PDF 电子版或纸质彩色打印件），或水电煤气缴费账单。
6. **现金储备**：
   - 随身携带 HK$1,000—10,000 港币现钞（用于在 ATM 或柜台存入第一笔激活金）。
7. **手机网络**：
   - 提前开通手机中国移动/电信/联通的境外漫游流量包，确保能随时接收内地银行短信验证码。

## 核心银行一：汇丰银行（HSBC One）

汇丰 One 是目前内地游客赴港性价比最高、功能最全的综合理财账户：**无账户管理费、无最低存款门槛、全球汇丰同名互转秒到且免手续费**。

### 方案 A：线上预填 + 抵港 App 极速激活（首选 ⭐⭐⭐⭐⭐）
1. **行前内地操作**：
   - 手机应用商店下载“HSBC HK”App。
   - 打开 App 选择“全新客户开户” → 选择“汇丰 One” → 拍摄身份证与通行证，填写个人基本信息、雇主职业与常住地址。
2. **28 日到港后激活**：
   - 早晨 08:00 过关进入香港境内，手机连接移动网络并开启手机 GPS 定位。
   - 打开 App 继续流程，系统自动识别当前位于香港境内。
   - 上传当天的出入境记录 PDF 文件及入境小白条照片，完成人脸活体识别。
   - 审核通过后即时生成账号，可直接添加到 Apple Pay 使用，实体 Mastercard 扣账卡后续邮寄至内地住址。

### 方案 B：尖沙咀分行现场柜台办理（稳妥保底 ⭐⭐⭐⭐）
若线上审核遇阻或需要现场直接领取实体卡，直接前往分行：
- **推荐网点**：**汇丰尖沙咀分行**（尖沙咀弥敦道 82-84 号，港铁尖沙咀站 B1 出口步行 2 分钟，距离科学馆仅 800 米）。
- **到达时间**：建议早晨 09:15-09:30 抵达取号。
- **开户沟通要点**：
  - 开户目的：如实回答“经常来港旅游消费、日常港币结算、海外购物及港股理财配置”。
  - 资金来源：工薪收入/个人积蓄。
- **现场拿卡**：
  - 柜台办理约 30-40 分钟，柜员核验材料无误后当场发卡（红狮子 Mastercard 借记卡）。
  - 拿到卡后在分行 ATM 机修改初始密码，存入 HK$1,000 现金完成激活。

## 核心银行二：ZA Bank（众安银行）线上秒批

香港最大的持牌虚拟银行，存款受香港存款保障计划保障（最高 80 万港币），全线上操作，不用排队。

### 操作步骤
1. 抵达香港境内后（连手机漫游或分行 Wi-Fi），下载并打开“ZA Bank”App。
2. 点击“开立账户”，选择“内地居民访港开户”。
3. 拍摄身份证、港澳通行证以及早晨拿到的入境小白条。
4. 人脸识别，填写个人邮箱和内地收件地址。
5. 提交申请后，系统通常在数分钟至当天完成审批下户，后续实体 Visa 卡免费邮寄到内地。
