# 香港开户

只我一个人办。四个目标：美股券商入金、绑 AI 订阅、收创作者收益、实体大行卡备用。

可用工作日 09.29、09.30（09.26 公众假期、09.27 周日、10.01 国庆日银行关门；09.28 迪士尼）。一个人一天能办完主体，09.30 整个上午是备用窗口。

## 一、港卡两张

### 汇丰 One（主力）

条件（[汇丰官网](https://www.hsbc.com.hk/zh-cn/international/banking-in-hong-kong/)）：

- 港澳通行证有效期 ≥ 6 个月，18-75 岁，新客户
- 手机支持 NFC，人在内地即可在 HSBC HK App 提交
- 内地提交后 **90 天内到港用 App 激活**：需要 GPS 定位 + 出入境记录

费用：2026-01-01 后新开的非香港身份证客户，平均全面理财总值 < HK$10,000 收 **HK$100/月**（[官方原文](https://www.hsbc.com.hk/zh-hk/accounts/products/one/)）。激活后立刻存入 ≥ HK$10,000。

**这 1 万港币怎么准备**：
- **方案 A（最稳，零手续费）**：出发前在内地银行（工行/招行/中行等）预约兑换好 **HK$10,000 港币现钞**随身携带入港（未超国家外管局 2 万元人民币或 5,000 美元等值外币携带限额），激活后直接在汇丰柜台或自动存款机（CDM）存入。
- **方案 B（备选）**：携带余额充足的内地银联借记卡，在香港汇丰 ATM 直接取现港币（每卡每日境外取现限额等值 1 万元人民币，注意各行取现手续费），取出后在 CDM 存入。
- ❌ **不要指望跨境电汇当天到账**：跨境转账通常需要几小时至 1 个工作日，无法在 11:00 准时到账用于柜台激活。

### ZA Bank（零成本备份）

条件（[ZA 官网](https://bank.za.group/zh-hk)）：申请时必须身处香港；内地身份证原件（有效期 ≥30 天）；内地手机号能在港收短信；出入境证明；无最低存款无月费。ZA 无实体分行，人在香港开 App，审核最长 5 个工作日。

⚠️ **核心网络避坑（极重要）**：申请时必须开启 GPS，且**必须连接香港本地网络（酒店 Wi-Fi、汇丰分行 Wi-Fi、或香港本地 SIM 卡）**！若直接使用内地手机卡漫游蜂窝网络，流量会经内地网关回传，IP 显示为内地，系统会直接判定「不在香港境内」而导致申请被拒！

## 二、美股券商

| 券商 | 状态 |
| --- | --- |
| 富途、老虎、长桥、华盛 | 已不接受内地居民直接开户，不用试 |
| **Webull（微牛）** | 可线上开，内地身份可用 |
| 盈立 Usmart | 可线上开，**但出金投诉密集**，见下 |
| 复星 | 可开 |

**盈立的坑**（小红书多篇高赞投诉）：①有人出金受阻 [1]；②汇率差 + 出入金手续费两头吃 —— 有人 3,400 元入金、一晚赚 11 美元、出金后只剩 3,417 元 [2]。

**对策**：

- 首选 **Webull**；盈立作备份，出金前先小额试一次
- **入金一次到位**（比如 2 万港币级），不要小额反复进出 —— 每次换汇+手续费都会磨损本金
- 出金前算清：平台换汇价 vs 官方中间价的差，通常值不值得当周出

**入金路径**：港卡（汇丰/ZA）→ FPS 转数快或 eDDA 绑定 → 券商账户。

⚠️ **eDDA 绑定可能失败**：汇丰账户主证件是港澳通行证，券商登记常用内地身份证，证件类型不一致绑不上；扣款失败可能收 HK$180。开户时就向银行确认登记证件口径。

## 三、AI 订阅（Claude / ChatGPT / Codex）

**先纠正两个误解：①港卡不等于能订阅成功；②你的招行卡也不行（官网直刷）。**

根本原因在官方白名单：**OpenAI 与 Anthropic 的支持地区名单里没有香港，也没有中国大陆**，付款卡必须由支持地区银行发行（[OpenAI 官方](https://help.openai.com/zh-hans-cn/articles/7232916-why-was-my-credit-card-declined)）[3]。

**X 上一手实测的时间线**（[招行全币种 Visa 为例](https://x.com/qisi_ai/status/1988855402491240774)）：

| 通道 | 2025-2026 实测倾向 |
| --- | --- |
| 官网填卡号（Stripe） | 2025-11 有过成功窗口 [16]；**2026 年大量被拒**，你的招行全币种卡也在被拒之列 [4] |
| Safari Apple Pay | 2026-01 教程吹爆，**同期一手大量打脸**；Claude 比 ChatGPT 更严 [5] |
| **Google Play 内购** | **2026 年仍是主流成功路径**，招行全币种绑 Play 有一手存活 [6] |
| PayPal 绑老账号 | 偶发成功（账号要老） |
| 野卡/虚拟卡 | 不要碰：代充封号、卡被封余额拿不回 [7] |

⚠️ **不要在同一账号上反复试卡** —— 有实测连试多种组合后账号被打成异常 [8]。

### 你的最优订阅路径

1. **立刻可用（不用等香港）**：招行全币种 Visa → 安卓 **Google Play 内购**订 Claude/ChatGPT。这是 2026 年一手存活最多、且你现有卡就能走的通道 [6]
2. **到港后增加一条**：ZA Bank 卡 + 港版支付宝（AlipayHK）订 ChatGPT，有一手「还没失败过」[9]
3. **兜底**：App Store 礼品卡（港区或美区 ID）
4. **Claude Code / Codex 额外一道坎**：客户端登录要支持地区手机号，内地/香港号码常过不了验证，实测用 Giffgaff（英国虚拟号）收验证码 [10]。行前准备一个

**订阅 ≠ API**：有人 Plus 港卡扣款成功，但 platform.openai.com 绑 API 被拒、地区选香港直接无法继续 [11]。Codex 的 API 额度走 platform，比订阅更严。

**经典白/万事达信用卡**：X 上**没有任何人**把经典白和 ChatGPT/Claude 扣款写在一起的成功或失败实测 —— 没有数据，别拿主力卡去试，试挂了影响行程支付。

## 四、创作者收益（X/Grok）

X 的广告分成唯一打款通道是 **Stripe** [17]。

- **收款端实测**：香港汇丰银行卡「最稳」，或 Wise 港币账户（费用更低）[14]
- 门槛：Premium 订阅、≥500 关注者、近 3 个月累计 1500 万次浏览 [15]
- 路径：Stripe 香港个人账户（Gmail 注册）→ 绑汇丰港币账户 → X 后台开通收益分享

这一项不需要在香港现场办（Stripe 线上开），但**汇丰账户激活后才能收款**，所以香港这趟把卡激活是前置条件。
