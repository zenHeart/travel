# 大屿山

09.27（周日）全天。昂坪360 缆车 + 天坛大佛 + 大澳渔村。

东涌线与次日的迪士尼同一方向。

## 缆车票价

[官方缆车门票页](https://www.np360.com.hk/sc/tickets-promotions/tickets-tours/cable-car-tickets)。单程约 25 分钟，可选标准车厢、水晶车厢、全景缆车。

| 票种 | 官方原价 |
| --- | --- |
| 标准车厢 单程（成人） | HK$205 |
| 标准车厢 来回（成人） | HK$295 |

授权平台常有折扣（Trip.com 标准来回约 HK$181、Klook 约 ¥195），**出发前比价，但只走授权渠道**。

带娃建议：**去程缆车、回程巴士**（省一段排队，也换个风景），或直接买来回票图省事。水晶车厢玻璃地板对娃有吸引力，但恐高的孩子慎选。

官方另提供**电子排队服务**，出发前在官网登记可减少现场排队。

## 三个点分别是什么

**天坛大佛**
坐落山顶，需登 268 级石阶才能到佛像基座。娃走不动就在下面平台看，视觉冲击已经足够。

**宝莲禅寺**
大佛对面，有斋菜可吃。

**昂坪市集**
仿古街区，有缆车探知馆等室内景点。缆车停运时这里照常开放。

**大澳水乡**
香港最后的渔村，水上棚屋是招牌。码头有小艇出海看**中华白海豚**，约 20-30 分钟一趟，另行收费，能否看到靠运气。

## 带什么

- [ ] 薄外套（缆车和室内冷气）
- [ ] 帽子、防晒霜：大佛平台和大澳都几乎没有遮阴
- [ ] 超轻雨衣
- [ ] 好走的鞋（大佛石阶 268 级）
- [ ] 港币现金（大澳小店、观豚船多收现金）
- [ ] 水和零食

## 弹性方案：娃累了就砍大澳

12:30 在昂坪评估娃的状态。累了就取消大澳：市集慢逛 + 早午餐后，14:00 缆车下山，15:00 前回酒店午休。大佛和缆车已经值回这天，大澳留给下次。

去大澳后再想撤就难了：11 号巴士每 5-45 分钟一班（[嶼巴官网](https://www.nlb.com.hk/route/detail/14)），周日返程等 2-3 班很常见；等不及可在大澳的士站搭的士回东涌。

## 提醒

- **周日人多**，缆车早上排队最长，官网预购 + 电子排队能省不少时间
- 大风或雷暴时缆车会停运，出发前看[香港天文台](https://www.hko.gov.hk/tc/index.html)；停运时东涌有巴士 23 号线上昂坪，但盘山路久
- 大澳巴士班次不密，返程要看好末班时间
- 缆车恐高的娃，去程可选巴士上山、回程再坐缆车下山（下山视野更开阔且心理压力小）
