# 前期准备

只为这条路线准备：**25—26 珠海长隆，27 深圳入住，28 香港当天往返，A 组 28 晚／29 下午返程。**

## 先锁四件事

- [ ] A 组先选返程日、出发站和时段，推荐 29 日下午。没有车票就不承诺 28 日晚能赶到。
- [ ] 珠海酒店与套票：25、26 两晚是否已订；如果 25 日需玩满一天，另核 24 日抵达交通与住宿。
- [ ] 深圳酒店：A 组 27—29 两晚，B 组暂 27—30 三晚；28 日晚走版 A 组只住 27 日并提前确认退房寄存。
- [ ] 办卡：确定主银行和已有申请状态；需分行时确认 28 日上午服务，暂按汇丰优先。

没有提供的订单一律记为未确认，不能把建议日期当已订。

## 车票起售日

铁路官方现行预售期为 **15 天，含当天**。按此计算下表；各站具体起售时刻、临时调整和车次以 12306 为准。[S22]

| 乘车日 | 对应起售日 | 要查的方向 |
| --- | --- | --- |
| 09.24（如提前抵达） | 09.10 | 武汉 → 珠海一侧 |
| 09.25 | 09.11 | 武汉 → 珠海一侧；仅当天才出发时使用 |
| 09.27 | 09.13 | 珠海 → 深圳联程，仅选择铁路转场时 |
| 09.28 | 09.14 | A 组深圳 → 武汉晚班；赴港如用高铁也查这天 |
| 09.29 | 09.15 | A 组深圳 → 武汉下午班 |
| 09.30 | 09.16 | B 组深圳 → 开平南 |
| 10.03 | 09.19 | B 组开平南 → 武汉 |

截至 09.07，上述日期尚未进入该预售窗口，**不列旧车次、不写余票已核实**。联程建议预留至少 60 分钟同站换乘；首段、次段都确认有票才完成交通安排。

## 证件与通讯

- [ ] 逐人检查港澳通行证、赴港签注次数及有效期，两个孩子单独核对；本方案只安排 28 日一次赴港。
- [ ] 铁路购票所用证件原件与出入境证件分别备齐，不把证件副本当原件替代。
- [ ] 家人与你分开时，两边各有可用手机、数据、联系渠道和充电宝。
- [ ] 保存酒店、科学馆汇合点、口岸及返程车站定位；按实际酒店地址导航。
- [ ] 银行材料放私人设备，别上传旅行站点、群公告或共享攻略。

## 27 日晚把行李分成两类

| 留深圳 | 随身赴港 |
| --- | --- |
| 大箱、后续几天衣物、非当天洗漱用品、长隆纪念品 | 各人通行证、必需证件、手机、少量现金、有效交通票 |
| B 组开平行李 | 你自己的银行材料与备用电源 |
| A 组独立整理的返程箱 | 孩子换洗衣服一套、水、小零食、湿巾、薄外套、雨具与帽子 |

按孩子实际步行能力决定是否带辅助装备，**不额外默认购买推车、腰凳或背带**。这一日靠少走、坐下休息与早点回深圳控制体力。

## 出发前两天及当天

- [ ] 核对长隆当日开放、演出和套票权益，不把其他游客的早入园资格套用到自己订单。
- [ ] 复核深圳酒店儿童入住与早餐、27 日接送车型和行李容量。
- [ ] 香港天气查看 [天文台](https://www.hko.gov.hk/tc/index.html)，口岸与交通查看官方公告。具体天气目前未预测。
- [ ] 科学馆周一 10:00 开；孩子已满 4 岁不按年龄自动免票，学生证明是否合格需核对。[S3]
- [ ] 28 日先看主卡状态再出发；接受材料未更新或审核未结束时办卡无法当日完成。
- [ ] 28 日晚走版：早晨完成退房与寄存，不把这件事留到回深圳后。

## 不再购买／安排

不新增香港住宿、迪士尼票与入园预约、昂坪缆车票，也不安排 29、30 日香港分行补办。如果旧订单已支付，先查退改条款后由本人决定，本次没有自动取消任何订单。
