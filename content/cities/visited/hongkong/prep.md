# 前期准备

今天 2026-09-03，距出发 09.25 还有 **22 天**。每条都标了「去哪做」，点链接直达。

## ⚠️ 贯穿全程的硬约束

**签注只够进出香港各一次。**

- 09.26 从福田口岸进港，A 组 09.29 / B 组 09.30 离港，签注即用完
- **进港时必须带走全部行李**，深圳酒店只住一晚，不能寄存大件
- 进港后到离港前**不能回深圳**
- 深圳要买的 09.25 当天买完；香港要买的离港前买完

## 一、证件

- [ ] **逐本翻开核对 6 本港澳通行证的有效期** —— 不是凭印象。汇丰要求**剩余有效期 ≥ 6 个月** [1]
- [ ] **单独核对两个娃的证件** —— 儿童证件有效期通常只有 5 年，最容易过期
- [ ] 核对每本的**赴港签注剩余次数**，确认确实是一次往返
- [ ] 需要补办或续签 → [国家移民管理局政务服务平台](https://s.nia.gov.cn/mps/bszy/wlgaot/sqgowl/201903/t20190313_1002.html) [2]
- [ ] 6 张身份证原件在手
- [ ] 全部证件拍照存手机 **+ 打印一份纸质备份，与原件分开放**

## 二、银行卡

完整流程见 [香港开户](./bank-2026.md)。

### 09.03-09.05

- [ ] 4 位大人各自下载 **HSBC HK App**（安卓在[汇丰官网](https://www.hsbc.com.hk/zh-cn/international/banking-in-hong-kong/)下 APK）
- [ ] 确认手机**支持 NFC**（硬门槛，不支持就走不通）
- [ ] App 内提交线上开户申请，**截图保存参考编号**
- [ ] **职业信息按真实情况填** —— 填错会被秒拒 [3]
- [ ] **开通国际漫游 + 国际来电接听**：中国电信默认拒接海外来电，而[中银香港](https://www.bochk.com/)开户会打电话确认，接不到即失败 [3]

### 09.05-09.10

- [ ] 线上开 [Webull](https://www.webull.com.hk/) 或 [盈立 Usmart](https://www.usmartsecurities.com/hk/zh-cn/)
- [ ] ❌ 不要浪费时间在富途、老虎、长桥、华盛（已不接受内地居民直接开户）[4]

### 09.10 前 —— 每位大人一套资料包（PDF + 打印件）

- [ ] 身份证原件 + 复印件
- [ ] 港澳通行证（有效期 ≥ 6 个月）
- [ ] 内地地址证明：信用卡账单 / 水电燃气费单，近三个月，**须含姓名和地址**
- [ ] 收入证明：[个人所得税 App](https://etax.chinatax.gov.cn/) 纳税记录截图
- [ ] 资金证明：银行流水或理财持仓截图
- [ ] 职业信息写一张纸：单位名称、地址、电话

### 09.11-09.15

- [ ] 预约[渣打](https://www.sc.com/hk/zh/)或[中银香港](https://www.bochk.com/)，时段选 **09.29 或 09.30**
- [ ] 分行**避开中环、尖沙咀**，优先新界（元朗、粉岭）
- [ ] 预约确认短信截图存好

## 三、车票

全部在 [12306](https://www.12306.cn/) 抢。**提前 15 天放票**，先查[车站起售时间](https://www.12306.cn/)定闹钟。

### 09.10 抢 09.25 武汉 → 深圳北

- [ ] 提前在 12306 **录入全部 6 人实名信息**（含两个娃）
- [ ] 首选 **G391 09:00 → 深圳北 13:01**（4h01m，二等座约 ¥627.5）[5]
- [ ] 备选 G389 08:00→12:09、G1001 07:17→12:19 [5]
- [ ] **两个娃各买一张儿童票占座**：规则上每名成人可免费带一名未满 6 周岁、不占座的儿童，但 4 小时车程不占座不现实；购票须提供娃的**有效身份证明文件** [6]

### 09.11-09.15 抢 A 组 09.29 返程

- [ ] 二选一：[G388 西九龙 07:20 → 武汉 12:08](https://www.highspeed.mtr.com.hk/tc/trip-planner.html?id=WEK2WUH)（¥768 / HK$888）[7]；或西九龙 → 广州南 → 武汉转乘
- [ ] 前一晚是迪士尼，娃早起困难就选转乘

### 09.16-09.18 抢 B 组后半段

- [ ] **09.30 西九龙 → 开平南**：直达 [G6048 10:18 → 12:35](https://trains.ctrip.com/TrainBooking/xianggangxijiulong-kaipingnan/gaotie)（¥292）；或转乘 G6538 15:17 → 广州南 →（换 16 分）→ C6969 → 17:44 [8]
- [ ] **10.03 开平南 → 武汉**：[C6910 11:19 → 广州南 12:35 →（换 40 分）→ G394 13:15 → 武汉 16:34](https://trains.ctrip.com/TrainBooking/kaipingnan-wuhan/gaotie) [9]

- [ ] ⚠️ **只从[昂坪360 官网](https://www.np360.com.hk/)或官方授权平台买** —— 非授权渠道的票一经发现作废、不退款 [12]
- [ ] 昂坪360 官网登记**电子排队** [12]

- [ ] 全部订单**截图存手机**，离线可看

- [ ] 换**港币现金**：大澳小店、观豚船、[澳洲牛奶公司](https://www.openrice.com/en/hongkong/r-australia-dairy-company-jordan-hong-kong-style-dessert-r90)等只收现金 [18]

## 七、娃的准备

- [ ] **用卷尺量两个娃的净身高并记下来** —— 迪士尼门槛 81 / 95 / **102** / 112cm，**102cm 是 4 岁娃的分界线** [19]
- [ ] 常用药：退烧药、退热贴、创可贴、肠胃药、驱蚊
- [ ] 换洗衣物按每天 1.5 套备
- [ ] 帽子、防晒霜、小风扇
- [ ] **超轻雨衣**（比伞好用）
- [ ] **薄外套**（商场、港铁、缆车、餐厅冷气都很强）
- [ ] **降噪耳机**（看迪士尼烟花用；娃说怕就直接走）
- [ ] 平板下载离线动画 + 贴纸书（高铁 4 小时）
- [ ] **娃的餐具一套** —— 香港老店多数没有儿童餐具
- [ ] 零食与水壶
- [ ] 防滑好走的鞋，不要穿新鞋（天坛大佛 268 级石阶）
- [ ] ❌ **不带婴儿车** —— 迪士尼排队时不能推，只能锁在旁边 [20]

## 八、容易忽略的细节

- [ ] **香港太湿热，娃走不了太多路** —— 每天别排满，City Walk 为主 [15]
- [ ] **[香港科学馆](https://hk.science.museum/tc/web/scm/visit/opening-hours.html) 周四休馆**；09.26 是周六兼公众假期，开放 10:00-21:00 [21]
- [ ] **[生记粥面](https://www.openrice.com/en/hongkong/r-生記粥麵-yau-ma-tei-hong-kong-style-congee-r14329)周日及公众假期休息** → 09.26、09.27 都不开 [22]
- [ ] **[澳洲牛奶公司](https://www.openrice.com/en/hongkong/r-australia-dairy-company-jordan-hong-kong-style-dessert-r90)周四全日休息、只收现金** [18]
- [ ] **福田口岸不是 24 小时**，运行 06:30-22:30 → [深圳口岸办](https://ka.sz.gov.cn/bmfw/katgfw/) [23]
- [ ] 09.26 是香港公众假期 + 周六，**08:00 前过关**，先查[口岸实时人流](https://www.sb.gov.hk/chi/bwt/status.html) [24]
- [ ] 迪士尼**转转杯与小小世界 10:30 才开门**，提早入园那一小时刷不到 [19]
- [ ] 迪士尼**迷离大宅、4D 影院 4 岁跳过**；大型真人演出坐靠过道、随时能撤 [20][25]
- [ ] 赤坎入住定位「**游客中心北门**」→ 登记处录人脸 → 电瓶车送至酒店 [13]
- [ ] 「心经简林」翻修关闭中，不用规划 [12]
- [ ] 开平景点之间公交不便，**10.02 提前订好包车一天** [14]

5. **两个娃的签注有效期**
6. **09.10 抢 [12306](https://www.12306.cn/) 武汉→深圳北**
7. **开通国际来电** —— 中银打不通电话直接判开户失败
