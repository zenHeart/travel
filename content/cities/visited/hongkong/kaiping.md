# 开平碉楼与赤坎

10.01 - 10.02 两天，B 组。属于 [江门段](./jiangmen.md) 的核心内容。

开平碉楼是**世界文化遗产**，赤坎华侨古镇是近年重修开放的骑楼老镇。两者相距不远，但公共交通都不方便，**建议直接包车**。

## 一、赤坎华侨古镇（10.01）

### 基本信息

| 项 | 内容 |
| --- | --- |
| 开放时间 | 09:00-22:00（夜间演艺、灯光秀正常开放） |
| 成人票 | 150 元 |
| 优待票（小孩/老人/学生） | 75 元 |
| 限时双人票 | 282 元 |
| 购票 | 「赤坎古镇景区商城」小程序 |
| 预约 | **国庆假期建议提前在「开平赤坎」公众号预约**，演艺项目需单独预约 |

> 娃 4 岁，按优待票或免票口径确认（各景区对儿童身高/年龄标准不一，购票时看清）。

### 三条官方风景线

古镇官方把游览分成三条线，一天走完刚好：

| 风景线 | 载体 | 时长 | 带娃友好度 |
| --- | --- | --- | --- |
| **一河两岸风景线** | 潭江摇橹船（思源河乘船约 30 分钟） | 30 分 | ⭐⭐⭐ 坐着看，娃很稳 |
| **历史街道风景线** | 复古铛铛车（有轨电车） | 30-40 分 | ⭐⭐⭐ 娃对车的兴趣天然高 |
| **市井生活风景线** | 步行 | 1-2 小时 | ⭐⭐ 看大人体力 |

⚠️ **摇橹船与铛铛车都在门票之外另行收费。**

### 必打卡

- **骑楼老街（堤东路 / 堤西路）** —— 600 余座骑楼，中西合璧，是古镇的骨架
- **关族图书馆 & 司徒氏图书馆** —— 百年历史建筑，**免费开放**。两大宗族各建一座图书馆隔河相望，是赤坎最有故事的一组建筑
- **赤坎唐人街** —— 复古街区，文创、非遗手作、特色小吃
- **傍晚乘船** —— 看两岸骑楼倒影，氛围最好

### 建议节奏（10.01）

```
10:00 入镇 → 先坐摇橹船（上午光线好、人少）
12:00 午餐（镇内，赤坎煲仔饭/豆腐角）
13:30 娃午休（找有空调的茶室或回车上）
14:30 铛铛车绕镇一圈
15:30 步行骑楼老街 + 两座图书馆
17:00 收工，返江门市区
```

> 若娃状态好，可以留到晚上看灯光秀（开放到 22:00），但国庆夜间人流会明显上升，带娃建议早撤。

## 二、开平碉楼（10.02）

### 门票

| 景点 | 价格 |
| --- | --- |
| 自力村碉楼群 | 78 元 |
| 三景点联票（自力村 + 马降龙 + 立园） | 180 元 |

### 带 4 岁娃选哪两个

**推荐：自力村 + 立园。**

| 景点 | 特点 | 带娃 |
| --- | --- | --- |
| **自力村** | 碉楼群最集中，稻田环绕，最出片，是"开平碉楼"的标准形象 | ✅ 必去 |
| **立园** | 园林 + 碉楼结合，有水景和回廊，路好走 | ✅ 推荐 |
| 马降龙 | 竹林环抱，环境好 | ❌ 路程较远，带娃性价比低 |

只去两个点的话买单票更划算（78 + 立园单票），要去三个才值联票 180。**行前用当天实际单票价算一下。**

### ⚠️ 安全提醒

**碉楼内部楼梯陡窄、光线暗、扶手低**，是当年为防匪修的，不是给游客设计的。4 岁娃**必须全程牵手**，最好由大人抱着上下楼梯。有些楼层的窗口很低，别让娃自己扒窗。

### 建议节奏（10.02）

```
08:30 江门出发（包车约 1 小时）
09:30-11:30 自力村（上午光线拍碉楼最好）
11:30-13:00 午餐 + 车上午休
14:00-16:00 立园
16:30-17:30 返回江门
```

## 三、吃什么（开平/赤坎）

| 店 / 菜 | 地址 | 说明 |
| --- | --- | --- |
| **兴华黄鳝饭** | 赤坎一带 | 柴火黄鳝饭，**焦香锅巴是灵魂**。赤坎最有名的一道 |
| **优之名鹅城** | 开平大道，**立园附近** | 开平美食地标，门面按《让子弹飞》鹅城场景修建，民国侨乡风格。卤水鹅、白切鹅、烧鹅、甜酸鹅都是招牌。有大型免费停车场 |
| **赤坎煲仔饭** | 赤坎镇内多家 | 百年传承。黄鳝、腊味、排骨、菜果等口味，烧鹅和煨汤也是招牌。饭点人多 |
| **赤坎豆腐角** | 赤坎镇 | 逾百年历史的风味小吃 |
| **古井烧鹅** | 新会古井镇 | 用开平马冈鹅，宋朝宫廷做法。若不顺路，在开平吃马冈鹅即可 |

**10.02 的午餐安排**：立园附近就是优之名鹅城，游完自力村过去吃马冈鹅，动线顺。

## 四、注意事项

1. **必须包车**。开平各景点之间、以及江门到开平，公共交通都很不便。国庆期间现场找车贵且难，**提前订好一天的包车**。
2. **国庆人流**：赤坎与碉楼都不是顶流景区，但 10.01 仍是全年高峰之一。上午早点到能明显错开。
3. **防晒**：碉楼在稻田里，几乎没有遮阴。帽子、防晒、水必备。
4. **现金**：镇内老店与小摊有只收现金的。
