# 开平碉楼与赤坎

10.01 - 10.02，B 组。两地公交都不便，**包车一天**。

- **赤坎唐人街** —— 文创、非遗手作、小吃
- 傍晚乘船看骑楼倒影

## 开平碉楼（10.02）

| 票种 | 价格 | 说明 |
| --- | --- | --- |
| 自力村碉楼群（单点） | 78 元 | 碉楼最集中，稻田环绕，必去 |
| 立园（单点） | 100 元 | 园林 + 碉楼，路好走 |
| **立园 + 自力村 联票** | **150 元** | **本次买这个**，比单买两张省 28 元 |
| 三景点联票（+马降龙） | 180 元 | 马降龙路程远，本次不去 |

开放时间：立园 9:00-17:55，自力村 9:10-17:50（[实测整理](https://www.hopetrip.com/news/detail-8555.html)）。套票两天有效，单点门票当天有效（[江门本地宝](https://m.jm.bendibao.com/tour/5692.shtm)）。

### 当天节奏

```
08:30 江门出发（包车约 1 小时）
09:30-11:30 自力村（上午光线最好）
11:30-13:00 午餐
14:00-16:00 立园
16:30-17:30 返回江门
```

### 安全

碉楼内部**楼梯陡窄、光线暗、扶手低**，娃上下楼梯要牵手，有些楼层窗口很低，别让娃自己扒窗。

## 提醒

1. 提前订好一天包车，国庆现场找车贵且难
2. 10.01 是国庆首日，上午早点到能错开人流
3. 碉楼在稻田里几乎没有遮阴，帽子、防晒、水必备
4. 镇内老店与小摊有只收现金的
5. 门票价格与儿童票标准以官方购票渠道当日显示为准
